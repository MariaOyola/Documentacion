#  MÓDULO 4: SEGURIDAD 

## Descripción
Gestiona usuarios del sistema, estados, roles y permisos. Controla el acceso y la autorización dentro de la aplicación.

---

##  Tablas

- user_status
- security_role
- security_permission
- user_account
- user_role
- role_permission

---

#  Relaciones (Forma simple)

- person 1:1 user_account
- user_status 1:N user_account

- user_account N:M security_role → (tabla intermedia: user_role)

- security_role N:M security_permission → (tabla intermedia: role_permission)


---

#  Explicación de relaciones

##  Usuario

### Relación con persona

person 1:1 user_account

- Una persona tiene una cuenta de usuario  
- Una cuenta pertenece a una persona  

---

### Estado del usuario

user_status 1:N user_account


- Un estado → muchos usuarios  
- Un usuario → un estado  

Ejemplo:
- ACTIVO, INACTIVO, BLOQUEADO  

---

##  Roles

### Relación usuarios - roles

- user_account N:M security_role

 Se resuelve con:

user_role

---

###  ¿Qué significa?

- Un usuario puede tener varios roles  
- Un rol puede estar asignado a muchos usuarios  

---

###  Ejemplo

Usuario: Maria

Roles:
→ ADMIN
→ CLIENTE

---

##  Permisos

### Relación roles - permisos

security_role N:M security_permission


Se resuelve con:

role_permission

---

###  ¿Qué significa?

- Un rol tiene muchos permisos  
- Un permiso puede pertenecer a varios roles  

---

###  Ejemplo


Rol: ADMIN
→ Crear usuario
→ Eliminar usuario
→ Ver reportes

Rol: CLIENTE
→ Comprar
