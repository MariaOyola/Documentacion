#  MÓDULO 6: AEROPUERTO 

##  Descripción
Gestiona aeropuertos, sus terminales, puertas de embarque, pistas y regulaciones.

---

##  Tablas

- airport
- terminal
- boarding_gate
- runway
- airport_regulation

---

#  Relaciones (Forma simple)


address 1:1 airport

airport 1:N terminal
terminal 1:N boarding_gate

airport 1:N runway

airport 1:N 
---

#  Explicación de relaciones

##  Aeropuerto

### Relación con dirección

address 1:1 airport


- Un aeropuerto tiene una dirección  
- Una dirección pertenece a un aeropuerto  


---

##  Terminales


airport 1:N terminal


- Un aeropuerto → muchas terminales  
- Una terminal → pertenece a un aeropuerto  


##  Puertas de embarque


terminal 1:N boarding_gate


- Una terminal → muchas puertas  
- Una puerta → pertenece a una terminal  

---

##  Pistas


airport 1:N runway


- Un aeropuerto → varias pistas  

---

##  Regulaciones


airport 1:N airport_regulation


- Un aeropuerto → muchas regulaciones  

---

#  Ejemplo real


Aeropuerto: El Dorado

Dirección:
→ Bogotá, Colombia

Terminales:

→ T2

Puertas:
→ T1 → Gate A1, A2, A3

Pistas:
→ 13L/31R
→ 13R/31L

Regulaciones:
→ Seguridad internacional
→ Normas de equipaje
